# Prompter — Android

`../prompter` klasöründeki web uygulamasını APK içine gömen WebView kabuğu.

Derleme (Android SDK gerekli, `local.properties` içinde `sdk.dir=...`):

    ./gradlew assembleRelease

Çıktı: `app/build/outputs/apk/release/app-release.apk`
Kayıtlar galeride **Filmler › Prompter** klasörüne yazılır.
